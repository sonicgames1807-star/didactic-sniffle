# Trace Neon

Мобильное PWA-приложение для срисовки изображений с телефона. Работает прямо в браузере, поддерживает установку на домашний экран и хранит проекты локально на устройстве.

## Возможности

- обучалка из четырёх шагов;
- импорт из галереи и камеры;
- перемещение одним пальцем, масштабирование и поворот двумя;
- неоновый регулятор прозрачности и быстрые значения;
- сетка, отражение, поворот, сброс и фиксация рисунка;
- локальное сохранение проектов и настроек холста;
- адаптация под безопасные зоны, маленькие экраны и landscape;
- клавиатурная навигация и режим уменьшенного движения;
- автоматическая публикация на GitHub Pages.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы проекта.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. После push в ветку `main` workflow соберёт и опубликует приложение.

Все изображения и проекты хранятся в `localStorage` текущего браузера и не отправляются на сервер.
